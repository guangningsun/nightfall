# 暗夜幸存者 · 微信小游戏 v0.10.3

从网页 v0.4.3 迁移的原生微信 Canvas 版本，不使用 WebView、DOM、外部 CDN 或浏览器适配器。不需要 npm 安装或构建。

## 运行

用微信开发者工具打开本目录，确认项目类型为「小游戏」，点击编译。保留了原工程的 AppID；AppID 权限仍由当前登录微信账号决定。通过开发者工具的「预览」扫码进行手机验证。本次未上传或发布微信版本，也未改动服务器网页版。

默认竖屏；窗口变化时重算 Canvas、触控布局和安全区。宽窗口菜单自动双栏。未接入折叠屏专属铰链 API；根据微信提供的可用窗口尺寸自适应。

## 已迁移功能

- 三位角色及各自属性、极速/血月试炼开局选项。
- 15 分钟生存、自动索敌、虚拟摇杆、双指移动与冲刺。
- 像素主角、四类铠甲敌人、金币、宝石、伤害数字、粒子、月轮和冲刺残影。
- 最高 8 级武器、被动饰品、升级三选一、六条超武路线、精英宝箱。
- 瑟琳娜改为白发、紫帽长袍、法杖造型；独立星雷新星、冰霜结界和瞬移技能，拥有独立升级卡池及饰品。
- 星雷 VIII＋星辉水晶→苍穹雷域；冰霜 VIII＋寒冬吊坠→绝对零度。
- 圣所永久技能：生命上限、武器伤害、拾取范围、每秒回血，各 5 级。金币在结算后入账；购买后下局对所有角色生效，重启保留。
- 银弹 VIII＋猎魔徽章→炼狱星陨；月轮 VIII＋远古磁石→永夜月蚀。
- 05:00 后掉落的宝箱满足配方 80% 进化，10:00 后必定进化；以掉落时间判定。
- 普通怪生成量为初版 3 倍，上限 780；精英尺寸 2 倍；全体敌人生命 +15%。
- 精英 03:00 / 05:00 / 07:30 / 10:00 / 11:00；领主 11:30。15:00 白昼到来，无论领主是否存活都强制结束并结算胜利。
- 图鉴、操作指南、本地最近 10 局战绩，切后台自动暂停，回来后手动恢复。

战绩使用 `wx.getStorageSync` / `wx.setStorageSync`，不会自动迁移网页 localStorage。单人模式离线运行；v0.6.0 双人试验模式连接独立联机服务器，无微信登录、排行榜、广告或支付依赖。

## v0.6.0 双人远征试验版

### 发布流程

1. 从仓库 `site/` 打包（排除 `.DS_Store`、`._*`），解压到 `/opt/nightfall-site/releases/<新版本>/`，权限 644/755。
2. `ln -sfn` 把 `current` 指向新版本。
3. `nginx -t` 通过后 `nginx -s reload`。index.html 走 no-cache，发布后立即生效。

回滚：nginx 侧删除 `nginx.conf` 中 `include /opt/nightfall-site/nginx-location.conf;` 一行，`nginx -t` 后 reload；站点侧 `ln -sfn` 把 `current` 指回旧 release 目录即可。

### 浏览器 harness

`tools/harness/index.html` 用 fetch 实现了一个最小 CommonJS 加载器（含 ESM 转译与循环依赖处理），并以真实 Canvas 模拟 `wx` API，使小游戏能在浏览器中直接运行。`tools/harness/capture.js`、`capture2.js` 用 Playwright 批量截图。

运行方式（仓库根目录起静态服务后执行）：

```sh
python3 -m http.server 8899     # 另一个终端
node tools/harness/capture.js    # 主流程截图
node tools/harness/capture2.js   # 图鉴 / 天赋 / 攻城 / 英雄选择
```

截图默认输出到 `site/.shots/`（已 gitignore），需要放进官网的挑好后拷到 `site/assets/shots/`。playwright 模块按 `PLAYWRIGHT_PATH` 环境变量 → 本地 `node_modules` → 仓库 `node_modules` 顺序查找。

注意：`wx.createCanvas()` 无参调用返回的是**新建离屏画布**，不是主画布；只有带 `width` 参数时才返回指定尺寸画布。首个无参调用拿到主画布，后续为离屏缓冲。搞错这个语义会导致精灵缓存全画到主画布上。

### 克隆后运行

小游戏客户端无需构建，用微信开发者工具直接打开本目录即可。服务端依赖需自行安装：

```sh
npm ci --prefix server --ignore-scripts
```

仓库不包含 `node_modules`，也不包含 `server/data/`（运行时生成的玩家档案）。

### 网站数据口径

站点上所有数值均对齐源码：`talents.js` 的 `cost = ceil(base*100*1.5^当前等级)`、`server/world.cjs` 的城门 4500/7500/12000 与 `gold: 500 + 本局金币`、`engine.js` 的 `eliteTimes=[120,180,300,420,600]` 与敌人上限 2000。性能数字（快照 -94%、精灵缓存 3.4ms→1.9ms）来自本地自动化测试，站点已注明不代表真机帧率。
