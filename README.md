# 暗夜幸存者 · 微信小游戏 v0.5.3

从网页 v0.4.3 迁移的原生微信 Canvas 版本，不使用 WebView、DOM、外部 CDN 或浏览器适配器。不需要 npm 安装或构建。

## 运行

用微信开发者工具打开本目录，确认项目类型为「小游戏」，点击编译。保留了原工程的 AppID；AppID 权限仍由当前登录微信账号决定。通过开发者工具的「预览」扫码进行手机验证。本次未上传或发布微信版本，也未改动服务器网页版。

默认竖屏；窗口变化时重算 Canvas、触控布局和安全区。宽窗口菜单自动双栏。未接入折叠屏专属铰链 API；根据微信提供的可用窗口尺寸自适应。

## 已迁移功能

- 三位角色及各自属性、极速/血月试炼开局选项。
- 15 分钟生存、自动索敌、虚拟摇杆、双指移动与冲刺。
- 像素主角、四类铠甲敌人、金币、宝石、伤害数字、粒子、月轮和冲刺残影。
- 最高 8 级武器、被动饰品、升级三选一、六条超武路线、精英宝箱。
- 瑟琳娜改为白发、紫帽长袍、法杖造型；独立星雷新星、冰霜结界和瞬移技能，拥有独立升级卡池及饰品。
- 星雷 VIII＋星辉水晶→苍穹雷域；冰霜 VIII＋寒冬吊坠→绝对零度。
- 圣所永久技能：生命上限、武器伤害、拾取范围、每秒回血，各 5 级。金币在结算后入账；购买后下局对所有角色生效，重启保留。
- 银弹 VIII＋猎魔徽章→炼狱星陨；月轮 VIII＋远古磁石→永夜月蚀。
- 05:00 后掉落的宝箱满足配方 80% 进化，10:00 后必定进化；以掉落时间判定。
- 普通怪生成量为初版 3 倍，上限 780；精英尺寸 2 倍；全体敌人生命 +15%。
- 精英 03:00 / 05:00 / 07:30 / 10:00 / 11:00；领主 11:30。15:00 白昼到来，无论领主是否存活都强制结束并结算胜利。
- 图鉴、操作指南、本地最近 10 局战绩，切后台自动暂停，回来后手动恢复。

战绩使用 `wx.getStorageSync` / `wx.setStorageSync`，不会自动迁移网页 localStorage。小游戏离线运行，无登录服务器、排行榜、广告或支付依赖。

## 工程

- `game.js`：原生入口，挂载 `GameGlobal.survivor`。
- `js/survivor/engine.js`：玩法、缓存像素渲染、Canvas UI、微信输入与生命周期。
- `images/survivor/`：本地角色/森林美术资源。
- `tests/smoke.cjs`：不依赖 DOM 的微信 API 模拟测试。
- `project.config.json`：保留 AppID，打包排除旧模板和测试。

旧飞机大战模板文件保留在磁盘，但不再引用且不参与打包。修改前的完整归档在相邻 `last_survivors_backups/quickstart-before-migration.tar.gz`。

## 版本规则

当前小游戏版本 v0.5.3；网页版停留 v0.4.3。后续每次上传/发布都递增版本，并同步更新 `VERSION` 常量、工程描述和本文件。不会自动将小游戏源码部署到 HTTP 9999 端口。

## v0.5.2 夜鸦独立技能

夜鸦自动发射可穿透、可回返的飞刃，沿行进路线布置毒刺陷阱；主动暗影突袭沿移动方向穿阵伤敌。独立八项强化包含飞刃、陷阱、鸦羽印记、剧毒原液、疾刃手法、猎场布置、影袭精通、致命直觉。全满后提供战地补给，避免升级界面无选项。

回旋飞刃 VIII＋鸦羽印记→千鸦刃雨；毒刺陷阱 VIII＋剧毒原液→噬魂毒沼。宝箱时间规则与其他角色一致。

长期迭代依据见 [DESIGN.md](DESIGN.md)。本版通过自动化玩法及模拟 Canvas 回归，尚未完成真机视觉与性能验收。

## v0.5.3 微信转发

主菜单「分享给好友」、结算页「分享战绩」和右上角微信菜单支持转发给好友/群聊。战绩卡片标题包含角色、存活时间和击败数量。分享使用本地森林图片；战斗中打开分享会暂停，返回后手动继续。取消分享不改变金币或进度，不以拉起分享判定发送成功。

实现参考微信官方示例：https://github.com/wechat-miniprogram/minigame-api-typings/blob/master/test/game.test.ts 。分享模块无网络请求，不读取联系人。本版未上传微信平台；实际转发、卡片及好友打开需使用有访问权限的微信真机验收。

额外验证：`node tests/share.cjs`。
